# Paper figures

All data figures of the MTAP paper are generated by `make_all.py` with one shared style (`style.py`). Do not edit the figure files in `paper/` by hand. For the data itself (which file is which, how it was made) see `DATA.md` at the repository root.

## Reproduce all figures

```bash
export QOE_DRIVE_DIR="<path to Google Drive>/phd/research/major_revision"   # once, e.g. in ~/.zshrc
python figures/fetch_data.py   # copies the inputs from Google Drive to datasets/paper_figures/
python figures/make_all.py     # writes <name>.pdf and <name>.png into paper/
```

Then rebuild the paper (`cd paper && latexmk -pdf main.tex`). One figure only: `python figures/make_all.py --only fig09`.

`fetch_data.py` reads from `<QOE_DRIVE_DIR>/datasets/<game>/` (or `--drive-dir`). No path is stored in the code. Inputs are not in git. Regenerating all figures this way is pixel-identical to the figures in the paper.

## Style

`style.py` holds the rules every figure follows:
- Drawn at its final printed size (sn-jnl text width 372 pt) and included in LaTeX at natural size, with no `scale=` or `width=`.
- 8 to 9 pt Computer Modern (cmr10, embedded as TrueType), matching the body text.
- No title inside the chart: `save()` refuses a titled figure. The caption carries it.
- Fixed wording and units (`LABELS`), shared colours for QoE classes and traffic directions.
- Output: vector PDF (used by LaTeX) and a 600-dpi PNG.

## Window-size comparison (`fig_window`)

Runs through the feature extractor and the training code, not through `make_all.py`. The paper's figure used the original CoD extractor, which `--mode legacy` reproduces:

```bash
for w in 1 3 5 10 15; do
    python features/extract.py --game cod --window $w --mode legacy          # datasets/cod/features_cod_<W>s_legacy.csv
    python training/run_models.py --game cod --window $w --tag legacy        # CoD, three classes, no SMOTE
done
python figures/make_all.py --only fig_window                                 # reads datasets/cod/results/
```

The paper's window datasets are also on Drive (`datasets/cod/features_cod_<W>s_legacy.csv`), so the extraction step can be skipped. `run_models.py` needs scikit-learn below 1.8.
