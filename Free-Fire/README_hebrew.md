# מדריך פרויקט: אפיון תעבורה מוצפנת וחיזוי QoE

מדריך זה מרכז את מבנה התיקיות והוראות ההקמה עבור סביבת המחקר. המערכת תוכננה לעבד הקלטות משחק גולמיות, לחלץ מאפייני רשת (Features), ולאמן מודלים של למידת מכונה לצורך חיזוי מדויק של השהיית רשת (Ping).

## 📂 מבנה התיקיות

* **`First_Action`**: פעולות ראשוניות על הקלטות גולמיות, כולל סנכרון נתונים וזיהוי אוטומטי של ערכי פינג על גבי המסך (OCR).
* **`Feature_analysis`**: מחברות מחקר המוקדשות לחילוץ תיאורים סטטיסטיים רב-שכבתיים מתוך זרימות רשת (Flows) ויומנים ויזואליים.
* **`Training_Pipeline`**: תהליכי אימון, הערכה ואופטימיזציה עבור אנסמבל (Ensemble) מודלי למידת המכונה.

---

## ⚙️ הקמת סביבת עבודה וניהול תלויות

הפרויקט כולל מנגנון אוטומטי להקמת סביבת עבודה מבודדת ועקבית.

### 1. `requirements.txt` (מניפסט ספריות)

מגדיר את כל חבילות התוכנה הנדרשות להרצת הקוד:

* **עיבוד נתונים**: `pandas`, `numpy`.
* **ויזואליזציה**: `matplotlib`, `seaborn`.
* **ניתוח רשת**: `nfstream` (ניתוח זרימות), `openpyxl`, `xlsxwriter` (הפקת דוחות אקסל).
* **למידת מכונה**: `scikit-learn`, `xgboost`, `catboost`, `lightgbm`.

### 2. `setup_env.bat` (אוטומציית סביבה)

סקריפט Batch עבור Windows להקמה בשיטת **"לחיצה אחת" (One-Click Setup)**:

1. **זיהוי**: בודק קיום של סביבה וירטואלית קיימת (`venv_win`).
2. **יצירה**: במידה והיא חסרה, הסקריפט יוצר סביבה מבודדת חדשה כדי למנוע התנגשויות בין ספריות.
3. **התקנה**: מפעיל את הסביבה, משדרג את כלי ה-`pip` ומתקין את כל התלויות מתוך קובץ ה-`requirements.txt`.
4. **הפעלה**: במידה והסביבה כבר קיימת, הסקריפט פשוט מפעיל אותה עבור המשתמש.

## 🚀 הוראות הרצה

### אפשרות א': שימוש ב-VS Code (מומלץ למפתחים)

1. הרץ את `setup_env.bat` כדי לבנות או לאמת את תקינות הסביבה.
2. פתח את תיקיית הפרויקט בתוך **VS Code**.
3. פתח קובץ מחברת כלשהו (`.ipynb`).
4. לחץ על **"Select Kernel"** (בפינה הימנית העליונה) ובחר במפרש הפייתון (Python Interpreter) שנמצא בתוך תיקיית ה-`venv_win`.

### אפשרות ב': שימוש ב-Jupyter Notebook (ממשק דפדפן סטנדרטי)

1. הרץ את `setup_env.bat`.
2. בתוך חלון הטרמינל הפעיל, הקלד `jupyter notebook` ולחץ Enter.
3. הממשק ייפתח באופן אוטומטי בדפדפן ברירת המחדל שלך.
