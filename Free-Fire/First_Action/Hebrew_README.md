# 📂 First_Action - הכנת נתונים ראשונית למחקר QoE

ברוכים הבאים לשלב הראשון בפרויקט. תיקייה זו מהווה את ה"שער" למחקר, ובה מתבצעות כל הפעולות הראשוניות על הקלטות הרשת והווידאו הגולמיות של המשחק **"Free Fire"**.

## 🎯 מטרת התיקייה First_Action:

התיקייה מרכזת את כל הצעדים המוקדמים שחייבים לקרות ברגע שיש לנו הקלטות ביד. כאן אנחנו הופכים דאטה "מלוכלך" וגולמי למידע מזוקק שמוכן לניתוח מעמיק.

## 📜 הנחיות עבודה ופרוטוקול

הרידמי הזה נועד לתת מבט על כללי. בשביל להבין בדיוק מה מריצים קודם, באיזה שלב ואיך עוברים בין התוכניות, יש לעבוד עם קובץ הטקסט המפורט:
📄 פרוטוקול זיהוי פינגים בתיקיית תמונות.txt

## 🛠️ מבנה התיקייה ופירוט הקבצים

### 1. סקריפטים לתפעול ישיר

| שם הקובץ | תיאור הפעולה |
| --- | --- |
| `Cut_pcap_V5_gm.py` | חותך את סוף הקלטת הפיקאפ במקרה שזה המשיך להקליט הרבה אחרי המשחק (אם שכחנו לעצור) |
| `Ping_Verifier_None_V1_gm.py` | נועד לתיוג ידני של התמונות שיש עליהם None (מקפיץ חלון עם מספר הפינג וצריך לכתוב את הפינג) |
| `Ping_Verifier_V1.2_gm.py` | נועד לתיוג ידני של התמונות מחוץ לטווח שבגדרנו, בין X ל-Y בתוך הקוד  (מקפיץ חלון עם מספר הפינג וצריך לכתוב את הפינג) |
| `prefix_remover_V1_gm.py` | מסיר את כל סימוני ה-V מהקבצים לאחר שסיימנו לסמן את כל הקבצים שתויגוי בשמות הפינג |
| `rename_manager_V2_gm.py` | מתייג את הקבצים בשמות הפינגים (משתמש בקבצים שבתיקיית- file_to_use) |
| `quality_check_V3_gm.py` | בודק כמה תמונות קיבלו פינג `None`, כמה לא תויגו בכלל, כמה כאלה יש בכל תיקייה ושמות הקבצים המדויקים שקיבלו `None` או לא תויגו. |
| `fill_missing_frames_v2_gm.py` | דואג שהמידע יהיה שלם, ואיפה שחסרות תמונות הוא משלים עם תמונות לבנות. |
| `Error_Image_Collector_V1_gm.py` | מעביר את כל התמונות שהמודל לא הצליח לזהות - לתיקייה ייעודית, לשם אימון עתידי | 
| `Find_Missing_Pcaps_gm.py` | בודק אם יש תיקייה שחסר בה קובץ PCAP |


### 2. תיקיית המנוע הפנימי: `file_to_use`

בתיקייה זו נמצאים הרכיבים שהסקריפטים האחרים משתמשים בהם. **אין צורך להפעיל או לשנות אותם ידנית**, הם ה"מנוע" שרץ מאחורי הקלעים:

* **`ping_extractor_V33_SuperHybrid_gm.py`**: סקריפט החילוץ המתקדם שלנו, המשלב מספר שיטות לזיהוי אופטימלי של פינגים מתוך הווידאו.
* **`ping_renamer_V1_gm.py`**: אחראי על שינוי שמות הקבצים בהתאם לערכי הפינג שזוהו בזמן אמת.
* **`ping_model_final.keras`**: המודל המאומן (Deep Learning) שמזהה את הספרות בתמונות הפינג.
* **`digits_font/`**: מאגר נכסים ויזואליים המשמשים את המערכת ללמידה והשוואה של פונטים מהמשחק.
